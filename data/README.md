# data — справочники, демо-данные и модели

| Каталог | Что | В git |
| :--- | :--- | :--- |
| `reference/` | Нормативные справочники: исходный XLSX «Сводный перечень строительных работ», выдержки МРР-3.2.81, ТСН-2001, КСР | да |
| `seed/` | Демонстрационные данные: объект, календарный график, камеры и зоны, хронология снимков | да (снимки — отдельным архивом) |
| `models/` | Веса моделей: детектор, классификатор стадии | **нет**, `make models` |

## reference/

Первоисточники, из которых собраны справочники сервисов. Держим их в репозитории,
чтобы любое число в системе можно было проверить по документу.

Правило: **каждая нормативная величина в коде и в справочниках сопровождается ссылкой
на источник** — документ, раздел, таблицу. Без ссылки число считается выдуманным.

## seed/

```text
seed/
├── object.json         # демонстрационный объект и его ТЭП
├── schedule.xlsx       # календарный график с заложенными отклонениями
├── cameras.json        # камеры и полигоны зон на эталонных кадрах
└── images/             # хронология снимков: cam-<код>/YYYYMMDD_HHMMSS.jpg
```

Имя файла снимка — источник времени, если в EXIF его нет. Подпапка — код камеры.
Демо-данные содержат **заранее заложенные отклонения** (D2, D3, D4, D10);
`scripts/e2e.sh` проверяет, что система нашла именно их.

## models/

Веса в git не хранятся: они большие и меняются каждый день обучения.
`make models` скачивает актуальные. Имя файла содержит версию
(`yolo11s-lct-v3.onnx`), которая попадает в каждую детекцию — вывод воспроизводим.
