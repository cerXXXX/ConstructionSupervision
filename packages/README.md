# packages — общее между сервисами

Три пакета. Правило одно и жёсткое: **здесь не может быть доменной логики**.
Общая библиотека с бизнес-правилами превращает микросервисы в распределённый монолит,
где изменение в одном месте ломает пять сервисов.

| Пакет | Что | Кто использует |
| :--- | :--- | :--- |
| [`contracts/`](contracts/README.md) | Канонические enum-ы, снапшоты OpenAPI, перечень доменных событий | Все, включая фронтенд |
| [`py-common/`](py-common/README.md) | Инфраструктура Python: логи, конверт ошибок, health, HTTP-клиент, проверка API-ключа | Все Python-сервисы |
| [`ts-api-client/`](ts-api-client/README.md) | TS-клиент, сгенерированный из OpenAPI | `apps/web` |

Что сюда **не кладём**: правила отклонений, формулы прогноза, модели БД, схемы DTO
конкретного сервиса, клиентов к конкретным сервисам сверх базового HTTP-класса.
