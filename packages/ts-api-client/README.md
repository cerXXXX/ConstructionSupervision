# ts-api-client — типизированный клиент API

TypeScript-клиент и типы, **сгенерированные** из снапшотов OpenAPI
(`packages/contracts/openapi/*.json`).

## Правила

- **Руками не правится.** Любая правка будет затёрта следующей генерацией.
  Нужно другое поведение — меняется контракт в сервисе, затем `make contracts`.
- Единственный источник типов API для `apps/web`. Дублировать типы ответов
  в коде фронтенда запрещено.
- Результат генерации коммитится: сборка фронтенда не должна зависеть от поднятого бэкенда.

## Генерация

```bash
make contracts   # снапшоты OpenAPI → типы и клиент
```

CI проверяет, что сгенерированное совпадает с закоммиченным: разошлось — ошибка сборки.

## Что внутри

```text
ts-api-client/
├── src/
│   ├── types.gen.ts    # типы из OpenAPI: DTO, enum-ы, параметры
│   ├── client.ts       # тонкая обёртка над fetch: базовый URL, X-API-Key, разбор конверта ошибок
│   └── index.ts
└── package.json
```

Обёртка `client.ts` пишется руками один раз (она не генерируется) и делает ровно три вещи:
подставляет базовый адрес и заголовки, разбирает конверт `{"error": {...}}` в типизированное
исключение, прокидывает `request_id` в объект ошибки для показа пользователю.
