# scripts — служебные скрипты

Всё, что вызывается из `Makefile`. Скрипт делает одно понятное действие и печатает,
что он сделал.

| Скрипт | Что делает |
| :--- | :--- |
| `bootstrap.sh` | Первичная подготовка: `.env` из шаблона, создание бакетов MinIO, баз и ролей PostgreSQL |
| `fetch_models.sh` | Скачивание весов детектора и классификатора стадии в `data/models/` |
| `seed.py` | Демо-данные: объект, генерация графика через `pos-engine`, камеры, зоны, загрузка снимков хронологии, прогон анализа |
| `demo.py` | Проигрывание демо-сценария: три «дня» объекта с заложенными отклонениями, с паузами для показа |
| `health.sh` | Опрос `/health/ready` всех сервисов, сводная таблица |
| `contracts.sh` | Снятие снапшотов OpenAPI и генерация TS-клиента |
| `e2e.sh` | Сквозной сценарий на поднятом стеке с проверкой ожидаемых отклонений |
| `backup.sh` | Дамп трёх баз и зеркало бакетов MinIO |
| `reset.sh` | Полная очистка данных: тома БД, бакеты, очередь |

## Правила

- Скрипты идемпотентны: повторный запуск не ломает состояние.
- Никакой бизнес-логики: скрипт вызывает API сервисов, а не лезет в их базы напрямую.
  Единственное исключение — `bootstrap.sh` и `reset.sh`, которые работают с инфраструктурой.
- Все адреса и ключи берутся из `.env`, ничего не зашито.
- Скрипт, который что-то удаляет, спрашивает подтверждение либо требует флаг `--yes`.
