# Архитектурные решения (ADR)

Каждое значимое решение фиксируется коротким документом: почему сделали так, чем заплатили
и что рассматривали. ADR не переписывают — устаревший заменяется новым со статусом
«отменяет ADR-NNNN».

Шаблон: `Статус → Контекст → Решение → Последствия → Рассмотренные альтернативы`.
