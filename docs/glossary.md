# Словарь предметной области

Единая терминология для кода, API, интерфейса и питча. Если термин есть здесь — в коде
используется именно он, без синонимов.

| Термин | Английский идентификатор | Определение |
| :--- | :--- | :--- |
| **Объект** | `object` | Объект капитального строительства: жилой дом, школа, дорога. Корневая сущность системы |
| **ТЭП** | `tep` | Технико-экономические показатели объекта: этажность, площадь, секции, сваи, сменность |
| **Справочник работ** | `work_type` | Иерархический классификатор строительных работ (4 уровня) из исходного XLSX заказчика |
| **Веха / этап** | `stage` | Укрупнённый этап календарного графика с плановыми датами и ожидаемой техникой. В коде всегда `stage`, слова `milestone` и `schedule_item` не используем |
| **Фаза** | `phase` | Крупный блок графика: подготовительный период, подземная часть, надземная часть, контур и кровля, сети, благоустройство |
| **Правило вехи** | `stage_rule` | Ожидаемая на вехе техника: обязательная (`required`), допустимая (`allowed`), сигнатурная (`signature`) |
| **Сигнатура** | `signature` | Сочетание техники, появление которого фиксирует фактический старт вехи |
| **Класс техники** | `equipment_class` | Тип машины в таксономии системы: `excavator`, `dump_truck`, `tower_crane`, … Совпадает с меткой CV-модели |
| **Зона** | `zone` | Полигон на кадре камеры: котлован, пятно застройки, периметр, въезд, складирование, опасная зона |
| **Эталонный кадр** | `reference_frame` | Снимок с камеры, на котором один раз размечаются зоны |
| **Снимок** | `image` | Отдельное изображение с камеры с временем съёмки и идентификатором камеры |
| **Сессия наблюдения** | `session` | Окно 30 минут по объекту; все снимки всех камер этого окна. Единица, по которой считается состав техники |
| **Факт сессии** | `session_fact` | Агрегат «зона × класс техники × количество» после дедупликации между камерами |
| **Детекция** | `detection` | Одна распознанная единица техники: класс, рамка, уверенность, зона, статус |
| **Точка контакта** | `anchor` | Нижняя середина рамки — точка, по которой детекция относится к зоне |
| **Статус техники** | `state` | `WORKING` — есть признаки работы, `IDLE` — простой в зоне, `OUT_OF_ZONE` — вне рабочих зон, `UNKNOWN` — данных недостаточно |
| **Стадия объекта** | `stage_label` | Внешний вид объекта по фото: котлован, сваи, фундамент, каркас, фасад, благоустройство |
| **Видимость зоны** | `zone_visibility` | Доля зоны, попавшая в пригодные кадры сессии: `OK`, `PARTIAL`, `BLIND` |
| **Слепая зона** | `BLIND` | Зона, не видимая ИИ в сессии. По ней выводы не делаются, выдаётся «проверить вручную» |
| **Отклонение** | `deviation` | Зафиксированное несоответствие факта плану: коды D1–D10, с серьёзностью, фактами и снимками-доказательствами |
| **Доказательство** | `evidence` | Снимки и конкретные детекции, на которых основано отклонение |
| **Факты вывода** | `facts` | Все числа, по которым построено отклонение; основа объяснимости |
| **Индекс активности** | `activity_index` | Доля рабочих сессий дня с полным работающим комплектом техники, 0…1 |
| **Эффективный день** | `effective_day` | Сумма индексов активности; «день, отработанный в полную силу» |
| **Прогресс** | `progress` | Доля выполнения вехи, 0…1; ограничена сверху видимой стадией объекта |
| **SPI** | `spi` | Индекс выполнения графика: фактический прогресс, делённый на плановый на сегодня |
| **Прогноз окончания** | `forecast_end` | Расчётная дата завершения вехи при сохранении текущего темпа |
| **Задержка** | `delay_days` | Разница между прогнозной и плановой датой окончания, в рабочих днях |
| **Уверенность** | `confidence` | Насколько выводу можно доверять: `LOW` / `MEDIUM` / `HIGH`; зависит от объёма данных и видимости зон |
| **Критический путь** | `cpm_path` | Цепочка вех без резерва времени; задержка любой из них сдвигает сдачу объекта |
| **Резерв** | `total_float_days` | На сколько дней веха может сдвинуться, не сдвинув окончание объекта |
| **Ревизия плана** | `plan_revision` | Слепок графика и правил на момент правки; нужен для аудита бюджетного объекта |
| **Прогон анализа** | `analysis_run` | Однократный пересчёт сверки план-факт с фиксацией версий входных данных |
| **ПОС** | `pos` | Проект организации строительства; здесь — нормативный расчёт графика и потребности в технике |
| **WBS** | `wbs` | Иерархическая декомпозиция работ объекта |
