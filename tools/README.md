# tools — конфигурация инструментов

Общие настройки линтеров, форматтеров и CI, чтобы правила были одни на весь репозиторий,
а не семь разных.

| Файл | Что настраивает |
| :--- | :--- |
| `ruff.toml` | Линт и формат Python: правила, длина строки 100, порядок импортов |
| `mypy.ini` | Проверка типов: нестрогий режим, строгий — на `core/` и `services/` |
| `eslint.config.js`, `prettier.json` | Фронтенд |
| `.editorconfig` (в корне) | Отступы, переводы строк, кодировка |
| `ci/` | GitHub Actions: линт → тесты → сборка образов → e2e |

Сервисы не переопределяют эти правила у себя. Нужно исключение — оно добавляется сюда
с комментарием, почему.

## Конвейер CI

1. `lint` — `ruff`, `mypy`, `eslint`. Быстро, падает первым.
2. `test` — unit и api-тесты всех сервисов параллельно.
3. `contracts` — снапшоты OpenAPI совпадают с кодом; иначе ошибка.
4. `build` — сборка всех образов.
5. `e2e` — поднять стек, прогнать демо-сценарий, проверить ожидаемые отклонения.

На хакатоне допустимо гонять первые три шага локально через `make lint && make test`,
но перед сдачей конвейер должен пройти целиком на чистой машине.
